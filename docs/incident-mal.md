# Incident-mal

Bruk denne malen for hver hendelse elevene leverer.

## 1. Sammendrag

- Tittel:
- Dato og klokkeslett:
- Oppdaget av:
- Berorte systemer:
- Alvorlighetsgrad:

## 2. Symptomer

- Hva ble observert?
- Hvem meldte problemet?
- Hvilke tjenester eller brukere ble rammet?

## 3. Analyse

- Hvilke logger eller verktøy ble brukt?
- Hvilke Event IDs ble funnet?
- Hvilken arsak peker sporene mot?

## 4. Tiltak

- Hva ble gjort for a stanse eller rette feilen?
- Hvilke kontoer, tjenester eller systemer ble endret?
- Hvilken verifikasjon ble gjort etterpå?

## 5. Konsekvens

- Hva var virkningen for brukere eller drift?
- Hvor lenge var problemet aktivt?

## 6. Forbedring

- Hvordan kan tilsvarende hendelse forebygges?
- Hvilke logger, policyer eller rutiner bor forbedres?

## 7. Vedlegg

- Skjermbilder
- Kommandoer
- Utskrift fra dashboard
- Event Viewer eller PowerShell-utskrifter
